# tpt-av-cadence-vorbis

Ogg Vorbis (MDCT-based) decoder for the `tpt-cadence` audio codec suite.

**Status:** 🚧 Scaffolded only — not yet implemented.

This crate currently exists as a placeholder for the Vorbis decoder. It
depends on `tpt-av-cadence-core` and follows the same crate layout as the
other decoders in the suite, but no decoding logic has been written yet.
