# tpt-av-cadence-aac

AAC-LC decoder (ISO/IEC 14496-3) for the `tpt-cadence` audio codec suite.

**Status:** 🚧 In progress / not yet functionally correct. Decoding currently
produces wrong audio output; the root cause is under active investigation.
See [`todo.md`](../todo.md) at the repository root for detailed debugging
status.

This crate is not usable for real decoding yet — it exists as a scaffold and
active work-in-progress. Do not depend on it for production audio decoding.
