# Changelog

All notable changes to `tpt-av-cadence-wasm-demo` will be documented in this file.

This crate is `publish = false`. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- WebAssembly build feasibility spike: WAV decode exported through `wasm-bindgen`
  and checked by the Node harness.
- Decode exports for every format: AIFF, FLAC, MP3, AAC, Opus (Ogg), and Vorbis
  (Ogg), each with a matching `*_sample_rate` export. Fixtures are generated by
  `tests/gen_fixtures.rs`, and `test.js` checks each format end to end.
- CI `wasm` job: builds for `wasm32-unknown-unknown`, runs `wasm-bindgen`, then
  runs `node test.js`.

### Changed

- The `*_sample_rate` exports no longer decode the whole stream to read the rate
  (performance pass, 2026-10-06).
- Fixtures were regenerated after the encoder corrections, so they match the
  current encoders.
